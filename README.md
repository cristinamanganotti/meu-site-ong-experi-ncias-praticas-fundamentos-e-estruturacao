# Projeto ONG — União

Projeto web desenvolvido para uma Organização Não Governamental (ONG), com o objetivo de apresentar a organização, seus projetos e disponibilizar um formulário para cadastro de voluntários.

## 📌 Sobre o projeto

O projeto foi desenvolvido como uma atividade prática de desenvolvimento web, aplicando conceitos de **HTML5, CSS3 e JavaScript**.

A aplicação possui páginas institucionais, apresentação de projetos e formulário de cadastro, além de recursos visuais e scripts organizados em diretórios específicos.

## 🚀 Funcionalidades

* Página inicial da ONG;
* Apresentação dos projetos e iniciativas;
* Formulário para cadastro de voluntários;
* Navegação entre as páginas;
* Estilização das páginas com CSS;
* Utilização de JavaScript para funcionalidades e interações;
* Organização dos arquivos por tipo de recurso.

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura e organização semântica das páginas;
* **CSS3** — estilização, layout, Flexbox e Grid;
* **JavaScript** — funcionalidades e interações da aplicação;
* **Google Fonts** — utilização de fontes externas;
* **Git e GitHub** — controle de versão e armazenamento do projeto;
* **Validador W3C** — verificação da estrutura dos documentos HTML.

## 📄 Páginas

### Página inicial

Apresenta a ONG, sua proposta e informações institucionais.

### Projetos

Apresenta as principais iniciativas e projetos desenvolvidos pela organização.

### Cadastro

Disponibiliza um formulário para cadastro de voluntários.

## ✅ Validação

Os documentos HTML foram desenvolvidos seguindo a estrutura recomendada pelo HTML5 e podem ser submetidos ao **Validador W3C** para identificação de possíveis erros estruturais e de sintaxe.

## 🎓 Objetivo acadêmico

Este projeto foi desenvolvido como atividade prática com o objetivo de aplicar conhecimentos relacionados ao desenvolvimento web, incluindo:

* estrutura semântica HTML5;
* criação e organização de formulários;
* validação de documentos HTML;
* estilização com CSS3;
* utilização de Flexbox e Grid;
* organização de arquivos em diretórios;
* introdução à utilização de JavaScript;
* controle de versão com Git e GitHub.
