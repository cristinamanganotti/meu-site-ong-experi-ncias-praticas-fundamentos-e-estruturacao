# Projeto ONG

Projeto web desenvolvido em HTML5 para uma Organização Não Governamental (ONG).

## 📌 Sobre o projeto

O projeto tem como objetivo apresentar informações sobre a ONG, seus projetos e disponibilizar um formulário para cadastro de voluntários.

## 📂 Estrutura do projeto

* `index.html` — página inicial
* `projetos.html` — apresentação dos projetos da ONG
* `cadastro.html` — formulário de cadastro de voluntários
* `css/` — arquivos de estilização
* `imagens/` — imagens e demais recursos visuais utilizados no projeto

## 🛠️ Tecnologias utilizadas

* HTML5
* W3C Validator para validação dos documentos HTML

## ✅ Validação

Os arquivos HTML foram revisados e submetidos ao W3C Validator para identificação e correção de erros estruturais e de sintaxe.

## 🎯 Objetivo acadêmico

Este projeto foi desenvolvido como atividade prática para aplicar conhecimentos de, estrutura semântica HTML5, formulários, validação nativa e organização de arquivos web.
